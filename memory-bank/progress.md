# Progress

## What Works
- Sharpmake generates Kolibri.sln (root) and Engine/Client projects under Intermediate/ProjectFiles. **Balius prebuild removed**: build balius manually (Setup.ps1 or `cargo build --release` in balius/) before building the solution. Launch/Monolith no longer call AddSolutionPrebuildSteps/AddBuildBaliusPrebuildStepFirst.
- Per-project prebuild runs balius.exe (EngineDir, project name, source root, Git dir, config); balius copies headers, optional git diff/commit, writes target file, runs header-parser; output under Intermediate/HeaderParser/<ProjectName>/HeaderGenerated.
- Header parser (C++, CMake) emits .generated.h and .generated.cpp; postGenerated (s_dependencies_, cloneImpl, BOOST) to .generated.cpp. Tracking headers use **GetIncludePathForTracking** (path as-is, e.g. Components/Public/X.h). Optional **--max-jobs 1** or **HEADER_PARSER_MAX_JOBS=1** to run file loop sequentially. CommonProject adds HeaderGenerated path; projects can depend on header-parser vcxproj when it exists.
- **FastBuild PATH and LIB**: Utils (GetRustPathForFastBuild, GetVCLibPathForFastBuild, GetFastBuildLib, etc.); CommonProject sets AdditionalGlobalEnvironmentVariables["PATH"] and ["LIB"] for win64; MasterBff prepends Windows SDK Lib to LIB when needed (GetWindowsSdkLibPathForBff) so link.exe finds ntdll.lib.
- Core: TypeLibrary, Object/Resource/Component, IGraphicAPI (Abstracts::Resource*), no dependency on other runtime modules. Engine modules (~50): Core, Memory, RenderPipeline, D3D12GraphicInterface, Texture, Shader, Mesh, Shape, Animator, PhysicsManager, etc. Client project; Monolith/Launch.
